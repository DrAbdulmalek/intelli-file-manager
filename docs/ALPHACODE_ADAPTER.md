# AlphaCode Adapter — أدوات تفضيلات التصنيف عبر MCP المحلي

> **الحالة: واجهة جاهزة للتكامل — التكامل الفعلي مع AlphaCode GUI
> غير مثبت بعد** (وفق قواعد المهمة §8: لا ادعاء اكتمال بلا واجهة
> اتصال مثبتة). الجسر MCP موجود ويعمل محليًا، ويتطلب تسجيل الخادم في
> إعدادات AlphaCode (دعم MCP stdio) لتفعيل الاتصال الفعلي.

## البنية

التكامل مبني على جسر MCP الموجود (`src/integrations/alphacode_mcp_server.py`)
— لا خادم شبكي جديد. النقل: **stdio JSON-RPC محلي** (MCP protocol
`2025-11-25` مع توافق إصدارات أقدم).

### الأدوات السبع

| الأداة | القراءة/الكتابة | الوظيفة |
|---|---|---|
| `intellifile.get_suggestion` | قراءة | اقتراح التصنيف من التفضيلات أو null |
| `intellifile.record_user_correction` | مخزن التفضيلات فقط | تسجيل تصحيح — **يُطبَّق فقط مع `user_confirmed=true` صريح من الإنسان**، وإلا يبقى `pending_review` |
| `intellifile.explain_rule` | قراءة | شرح القاعدة (حالة/ثقة/تعارضات/مصدر) |
| `intellifile.list_applicable_rules` | قراءة | القواعد المطابقة لميتاداتا |
| `intellifile.confirm_rule` | مخزن التفضيلات فقط | تأكيد صريح يرفع الاستقلالية وقد يرقّي إلى stable |
| `intellifile.disable_rule` | مخزن التفضيلات فقط | تعطيل مع حفظ الحالة السابقة |
| `intellifile.enable_rule` | مخزن التفضيلات فقط | إعادة تفعيل بنفس الحالة السابقة |

**لا توجد أداة** نقل/نسخ/حذف/تنفيذ/undo في هذا الخادم — لا قبل هذه
الإضافة ولا بعدها (مثبت باختبار العقد المحدّث).

## حدود الأمان

1. **لا منفذ شبكي إطلاقًا** — stdio محلي فقط؛ أقصر من «localhost فقط».
2. **هوية العميل:** بوابة تهيئة MCP إلزامية قبل أي أداة
   (`Server not initialized` غير ذلك)، والنقل نفسه أنبوب مملوك لمستخدم
   نظام التشغيل — لا وصول من مستخدم آخر للأنبوب.
3. **لا shell / لا subprocess / لا popen** — مثبت بفحص AST في الاختبارات.
4. **لا cloud fallback** — كل شيء ملفات محلية.
5. **الخصوصية:** المسار الخام لا يُخزَّن (يُجزَّأ sha256 فورًا)؛ ميتاداتا
   العميل تُنقّى إلى الحقول المسموحة فقط؛ سجل العمليات الاختياري
   (`IFM_ADAPTER_OPS_LOG`) يسجل الوقت/الأداة/النتيجة **بلا أي payload**.
6. **payload غير صالح → خطأ أداة صريح**، ولا كتابة جزئية.

## التشغيل

```bash
# خادم جسر AlphaCode (stdio) — الأدوات التفضيلية تعمل مباشرة
python -m src.integrations.alphacode_mcp_server   # أو عبر AlphaCode MCP config

# متغيرات البيئة (اختيارية)
INTELLIFILE_AGENT_ROOTS=...        # جذور الجرد المسموحة (كما كانت)
IFM_PREFERENCES_JSON=~/.intellifile/preferences.json
IFM_FEEDBACK_JSONL=~/.intellifile/feedback_log.jsonl
IFM_ADAPTER_OPS_LOG=...            # اختياري — سجل عمليات مُجرَّد
```

## ما لم يُدمج بعد (صريح)

- **الاتصال الفعلي من AlphaCode GUI:** يتطلب تسجيل الخادم في إعدادات
  AlphaCode (دعم MCP stdio) — غير قابل للإثبات من هذا المستودع وحده.
- **مزامنة القواعد بين AlphaCode ولوحة سطح المكتب:** نفس المخزن
  (`preferences.json`) — تشترك فيه الأداتان تلقائيًا عند التشغيل على
  نفس المستخدم، بلا أي مزامنة سحابية.
