# IntelliFile Protocols — دليل الوكيل لأدوات MCP

## قبل أي عملية ملف
1. استدعِ `classify_path` لمعرفة حساسية المسار (الأسماء والامتدادات فقط — لا تقرأ المحتوى أبداً).
2. استرجع التفضيلات ذات الصلة: `preference_query(context=<اسم الأداة>)`.
3. إذا كان المسار حساساً: لا قراءة، لا OCR، لا استخراج نص — الحاجز ثابت وغير قابل للتجاوز مهما طلب المستخدم.

## عند نقل أو نسخ ملف
- استخدم `safe_move_file` / `safe_copy_file` دائماً — لا `os.rename` ولا `shutil` مباشر أبداً.
- **لا يوجد خيار overwrite** — محظور بعقد المستودع. إذا أرجعت الأداة `used_suffix=true`، أبلغ المستخدم بالمسار النهائي الفعلي.
- إذا أصرّ المستخدم على الاستبدال: اشرح أن العقد يمنعه، واقترح تراجعاً (`undo_last`) أو تعديلاً يدوياً واعياً خارج الأدوات.
- عند رفض الحاجز الحساسي (`محظور: archivo حساس...`): أوقف العملية فوراً ولا تحاول مساراً بديلاً لنفس البيانات.

## عند التراجع
- استخدم `undo_last` مع مسار `.ifm_undo.json` — لا تحذف ملفات يدوياً.
- الفشل الصريح (`success=false`) يعني وجود شاغل أو مشكلة — اعرض السبب على المستخدم ولا تكرر بأدوات أخرى.

## عند تقييم القواعد
- استخدم `evaluate_rule` (inline ruleset أو مسار YAML) قبل أي تنفيذ — النتيجة محاكاة بلا تعديل.
- الامتداد في القواعد **بلا نقطة** (`jpg` لا `.jpg`).

## حلقة Feedback — طبّقها بعد كل عملية تغيير حالة
1. احفظ `feedback_token` من رد الأداة (`_meta.feedback_token`).
2. إن عدّل المستخدم النتيجة يدوياً أو أعاد المحاولة فوراً → إشارة سلبية:
   `feedback_record(token, signal="negative", context=<الأداة>, condition=<الحالة>, preferred_action=<suffix|reject|ask_user>, note=<التصحيح>)`
3. إن قبلها وكمل مهمته دون تعديل → `feedback_record(token, signal="positive_implicit")`.
4. بعد عمليات حساسة فقط (لا مع كل خطوة): سؤال واحد قصير — «نقلته إلى `docs/report_1.txt` (لاحقة آمنة). هل هذا ما توقعت؟».
5. استدعاء `undo_last` على نتيجة أداة سابقة = إشارة سلبية قوية على تلك النتيجة — سجّلها.

## حدود التعلم
- `preferred_action` المسموح: `suffix` / `reject` / `ask_user` — أي طلب `overwrite` يُرفض من المخزن نفسه.
- التفضيلات تحسّن اختيارك للسلوك، لا تعدّل قرارات الأمان ولا تعطلها.
- التفضيلات المتقادة (strength < 0.05) لا تظهر — لا تعتمد على تفضيل قديم لم يُؤكد مؤخراً.
