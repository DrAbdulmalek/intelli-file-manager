## 8. القيود والافتراضات

1. **لا تنفيذ فعلي على القرص قبل البوابة 1** — قاعدة البيانات الحية `crops.db` يجب تأمين نسختين خارجيتين أولاً.
2. **التقرير المنتج هو وضع "fast"** (لا SHA-256، لا كشف تكرار) — للمسح الكامل بكشف التكرار يحتاج وقت أطول على fuseblk.
3. **جميع المخرجات موجودة داخل مجلد المشروع** `intelli-file-manager/` وفي المجلد المخصص `archive_sort_alphacode/`.
4. **لا استخدام لأي API خارجي** في قرارات الفرز (سياسة النطاق المطبقة).
